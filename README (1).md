# Lunettes intelligentes — dossier scientifique interactif

Site statique en français (HTML / CSS / JavaScript natif, aucune dépendance à installer).

## Contenu

- Introduction animée, fond de particules interactif, schéma de lunettes dessiné en direct
- Anatomie interactive des composants
- Laboratoire d’optique : simulation de la réflexion totale interne dans un guide d’onde (angle θ et indice n réglables)
- Diagramme radar comparant quatre architectures optiques
- Onglets, barres d’ordres de grandeur, accordéon, chronologie animée
- Deux simulateurs : autonomie de la batterie et densité angulaire de pixels
- Thème clair / sombre, navigation latérale, respect de `prefers-reduced-motion`

## Aperçu en local

Ouvrez `index.html` dans un navigateur (les polices Google Fonts nécessitent une connexion internet ; sans elle, des polices système sont utilisées).
